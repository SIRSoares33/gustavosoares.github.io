ITAÚ API

Visão Geral

O desafio do Itaú consistia na construção de uma API REST responsável por receber transações financeiras e calcular estatísticas em tempo real, sem uso de banco de dados.

Todos os dados deveriam ser armazenados exclusivamente em memória, respeitando regras rígidas de validação, padronização de endpoints e desempenho.

Minha Solução

Desenvolvi a API utilizando AspNet, implementando validação completa das transações, armazenamento eficiente em memória e cálculo otimizado das estatísticas dos últimos 60 segundos.

O projeto foi estruturado com foco em legibilidade, separação de responsabilidades, testes automatizados e tratamento robusto de erros.

Endpoints Implementados

POST /transacao

Recebe transações com validação de valor, data e formato JSON.

DELETE /transacao

Remove todas as transações armazenadas na memória.

GET /estatistica

Calcula estatísticas agregadas dos últimos 60 segundos.
