ToDo API

API REST para Gerenciamento de Tarefas

A ToDo API é uma aplicação backend desenvolvida em ASP.NET Core, com foco em boas práticas, segurança e arquitetura limpa, simulando um cenário real de produção.

API

Visão Geral

Este projeto foi desenvolvido com objetivo educacional e de portfólio, visando consolidar conhecimentos em desenvolvimento de APIs REST com ASP.NET Core, aplicando Clean Architecture, separação de responsabilidades e padrões modernos de projeto.

Funcionalidades Principais

🔐 Autenticação JWT

Autenticação segura utilizando JWT, com geração de tokens e validação baseada em claims.

👥 Controle de Usuários

Gerenciamento de usuários com permissões e controle de acesso baseado em roles.

✅ Gerenciamento de Tarefas

Criação, edição, listagem e exclusão de tarefas vinculadas ao usuário autenticado.

🛡️ Autorização por Roles

Proteção de endpoints com autorização baseada em perfis como Admin e User.

📦 Clean Architecture

Separação clara de camadas para facilitar manutenção, testes e escalabilidade.

🔌 API REST

Endpoints RESTful seguindo boas práticas de design e padronização.
